# 👻 GhostOS

**GhostOS** is an original gaming-focused desktop interface prototype built with HTML, CSS, and JavaScript. It currently runs in a web browser; it is not a bootable operating system.

## Features
- Player login screen (local demo profile)
- Animated boot screen
- Game library with add, launch-placeholder, and remove actions
- Wallpaper selector
- Accent-color and interface settings
- Demo app center
- Local browser storage for preferences, games, and installed app entries

## Run it
Open `index.html` in a modern web browser. No build tools or dependencies are required.

## Project files
- `index.html` — app layout
- `style.css` — visual design and responsive styling
- `script.js` — navigation, local data, game library, settings, and app center

## Limitations
This is a front-end prototype. Game launching, native app installation, hardware monitoring, and operating-system boot are not implemented. Data is stored in the current browser using `localStorage`.
